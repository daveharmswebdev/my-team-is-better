For the engineer

CSS approach: CSS Modules

Plain CSS, scoped per component — not Tailwind, not CSS-in-JS. Reasoning: apps/web already runs Vite (zero-config *.module.css support) and organizes components one-per-folder, so QuestionForm.module.css sits next to QuestionForm.tsx with no new build dependency. Scoping avoids the cross-component specificity collisions the design skill flags as the most common CSS bug in a project this size, and it keeps Storybook stories trivial — each story already imports its component; it now also imports one sibling stylesheet.

Tokens file

Drop the custom properties below into apps/web/src/styles/tokens.css, import it once in main.tsx before any component styles, and replace index.css's ad hoc rules with it.

:root {
  --bg: #F3ECDD; --surface: #FBF8F1; --surface-alt: #EAE0C9;
  --ink: #1C1A17; --ink-muted: #5B564C;
  --leather: #6B3423; --leather-strong: #4A2318; --on-leather: #FBF8F1;
  --gold: #A9781F; --gold-bright: #C89B3C;
  --navy: #1F2D50; --hunter: #2A5C3F; --brick: #8C2F2F; --slate: #6B665C;
  --rule: rgba(28,26,23,.18); --rule-strong: rgba(28,26,23,.32);
  --font-display: 'Anton', 'Arial Narrow Bold', sans-serif;
  --font-label: 'Barlow Condensed', 'Arial Narrow', sans-serif;
  --font-body: 'Barlow', 'Helvetica Neue', Arial, sans-serif;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { /* same tokens, dark values */ }
}
:root[data-theme="dark"] { /* same tokens, dark values -- explicit toggle wins both ways */ }

Wiring it into existing components

No JSX structure changes — add className to existing elements and a co-located .module.css per folder:

  • QuestionForm.tsx → styles.qform on the <form>, styles.qfield on each field wrapper div, a styles.casual variant on the "your team" wrapper, styles.btn on the submit button.
  • VerdictCard.tsx → styles.vcard on the <article>, styles.narration on the <blockquote>; the stamp badge is a new presentational <span aria-hidden>, no prop changes.
  • TeamCaseReceipts.tsx / ComparisonReceipts.tsx → styles.receipts on the <section>, styles.gameline per <li>, styles.kvGrid on the comparison <dl>.
  • VerdictError.tsx → styles.pick for the two chip-list cases, styles.plain + a user/system modifier for the other two.

Accessibility carried forward

  • role="status" on loading, role="alert" on all four error states — unchanged.
  • Every interactive element (chips, buttons, inputs) keeps a visible :focus-visible ring; none rely on color alone.
  • Loading animation and any future motion respect prefers-reduced-motion.
  • Text/background pairs hold WCAG AA in both themes; the stamp badge is decorative (aria-hidden) since "Certified Verdict" adds no information beyond the narration.
